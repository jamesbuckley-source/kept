What's new

Every change in this release, one card per feature. The full notes live with the release on GitHub.

  • 🎨

    A new mark

    The app icon, tray icon and settings header now carry the amber-and-ink Kept mark.

  • 💾

    Saving follows the clip

    Links save as shortcuts, colours as CSS, a GIF keeps its motion, and secrets ask before they leave the vault.

  • ☁️

    Cloud folder warning

    Choosing a data folder inside Drive or Dropbox now says what sync does to a live database.

  • 🗂️

    Sorted exports

    Save a mixed selection into Images, Text and Files folders, with a report of anything that had moved.
